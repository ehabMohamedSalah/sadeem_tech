This Flutter-based mobile application offers features such as user authentication (login, registration), product management, cart functionality, wishlist management, and user profile management. Below is a description of the key screens and their functionalities.

Key Features
1. Login Screen
The login screen allows users to sign in using their credentials (email and password).
 ![Screenshot 2025-05-01 212215](https://github.com/user-attachments/assets/36b4a428-7e31-465a-89ee-86b548b173cb)



2. Registration Screen
New users can create an account by providing their information, such as name, email, and password.
![Screenshot 2025-05-01 212221](https://github.com/user-attachments/assets/84738943-be7b-4a88-baff-f77d002f6a19)

 



3. Home Screen
The home screen showcases a list of products available for purchase, featuring their images, titles, and prices.
Users can search for products, view product details, and add products to their cart.
![Screenshot 2025-05-01 212105](https://github.com/user-attachments/assets/a1f52835-8bc7-4cb2-8c76-5b6ead32873b)




4. Product Details Screen
Users can view detailed information about a specific product, including a detailed description, price, and other relevant information.
From here, users can also add the product to their cart.
![Screenshot 2025-05-01 212114](https://github.com/user-attachments/assets/19cb130e-bcc1-4251-a343-8bd25f0904f0)




6. Cart Screen
The cart screen displays all the products added to the cart, including their price and quantity.
Users can proceed to checkout or remove items from the cart.
![Screenshot 2025-05-01 212145](https://github.com/user-attachments/assets/b7432a6a-4e33-4316-8389-5518941681f9)



6. Cart Detail Screen
Detailed view of each item in the cart, showing individual prices, quantities, and total cost.
Users can adjust the quantity of items or proceed to checkout.
![Screenshot 2025-05-01 212121](https://github.com/user-attachments/assets/aa0c3cd4-5f48-4e23-8ade-ad89ddf88a27)



7. Wishlist Screen
Users can add products to their wishlist for future reference or purchase.

The wishlist screen shows all the products users have saved.
![Screenshot 2025-05-01 212131](https://github.com/user-attachments/assets/7038d72d-0e6d-4c2f-8a8c-e1d4f825ac9d)
![Screenshot 2025-05-01 212135](https://github.com/user-attachments/assets/8052be70-8eb9-4146-b616-9b22c5b7c2cb)





8. Profile Screen
Users can view and edit their profile information, such as name, email, and password.
